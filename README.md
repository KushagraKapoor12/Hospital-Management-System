# Hospital Management System

A desktop-based Hospital Management System developed to simplify and automate hospital operations such as patient management, doctor records, appointments, billing, and staff administration.

## 📌 Project Overview

This project was created as an academic mini-project to improve the efficiency of hospital administration by replacing manual record handling with a digital management system.

The system provides an easy-to-use interface for managing:
- Patient records
- Doctor information
- Appointments
- Billing details
- Hospital staff data

---

## 🚀 Features

- 👨‍⚕️ Doctor Management
- 🧑 Patient Registration and Records
- 📅 Appointment Scheduling
- 💳 Billing and Payment Management
- 🏥 Hospital Staff Management
- 🔍 Search and Update Records
- 🗂 Database Connectivity
- 📊 Organized Data Handling

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/KushagraKapoor12/Hospital-Management-System.git
```

### 2. Open the Project
Open the project using:
- NetBeans
- IntelliJ IDEA
- Eclipse

### 3. Configure Database
- Create a MySQL database
- Import the SQL file (if available)
- Update database credentials in the project

### 4. Run the Project
Compile and run the main Java file.
